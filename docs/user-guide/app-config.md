# APP 配置

BroSDK 中的 APP 是账号下的接入单元，用来承载 `API Key`、`appSecret`、应用级存储策略、内核下载策略以及访问控制配置。它和浏览器环境 `env` 是两层概念：

- APP 配置：定义应用级能力、下载策略、存储策略。
- 环境配置：定义单个浏览器环境的代理、指纹、启动参数和持久化数据。

## 自定义 Logo

到控制台，进入 APP 修改页面，上传自定义的 Logo 图片。

## 配置内核自动更新

到控制台，进入 APP 配置页面，修改内核自动更新配置。
